# DalalSetu

Trusted network for Surat real estate agents, in Gujarati and English. Agents get listing attribution and anti-copy protection, buyer introduction records, commission agreements and offline payment tracking.

- `app/`: the agent app (React + TypeScript + Vite, wrapped for Android with Capacitor). See `app/README.md`.
- `project/`, `chats/`: the original Claude Design prototype and design conversation (`project/HANDOFF.md`).

## Download the Android APK

Every push to `main` builds an APK with GitHub Actions and attaches it to the
[latest release](../../releases/tag/latest).
